# IQTestReal

IQTestReal is a free, transparent IQ-style reasoning assessment built with React, TypeScript, Vinext, Vite, and Nitro. It is designed for practice and education, not clinical diagnosis.

## Online development

Requirements: Node.js 22.13+ and npm.

```bash
git clone https://github.com/ayushphiyak-dev/IQTestReal.git
cd IQTestReal
npm install
npm run dev
```

Open the URL printed by Vite in your browser. Dependencies are installed online from npm; no offline package bundle or manual cache is required.

## Vercel deployment

Import this repository into Vercel. The repository already defines the deployment settings:

- Install command: `npm install`
- Build command: `npm run build`
- Output directory: `.output`
- Framework preset: automatic detection or Other

Vercel installs dependencies from npm and serves the Nitro output generated by the build.

## Validation

```bash
npm run lint
npm run typecheck
npm run build
```
