# IQTestReal

IQTestReal is a free, transparent IQ-style reasoning assessment built with Next.js, React, TypeScript, Vinext, and Cloudflare-compatible Sites tooling.

## Local development

```bash
npm install
npm run dev
```

Quality checks:

```bash
npm run typecheck
npm run lint
npm run build
```

The assessment randomizes 15 questions across five reasoning categories and stores completed attempts locally in the browser. Results are labelled Estimated IQ and are not clinical diagnoses. Advertising, analytics, and contact delivery remain disabled until explicitly configured.
