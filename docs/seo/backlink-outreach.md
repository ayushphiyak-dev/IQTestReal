# IQTestReal backlink outreach plan

This is a small, manual, quality-first prospect list—not an automated link campaign. Do not buy links, exchange links, post comments for links, create accounts, or submit forms in bulk. A prospect should receive one genuinely useful idea and a no-pressure option to ignore it.

## What we can offer

The most linkable asset is the original [reasoning categories guide](https://iqtestreal.com/articles/reasoning-categories-explained), which contains ten worked examples and explains logic, pattern, numerical, spatial, and analogy reasoning in plain language. Supporting destinations are the [logic puzzle guide](https://iqtestreal.com/articles/logic-puzzles-for-beginners), [number sequence guide](https://iqtestreal.com/articles/number-sequences-explained), and [score guide](https://iqtestreal.com/score-guide).

Pitch the resource only where it answers a real reader need—for example, a teacher resource page that wants a free practice activity or a puzzle index that wants a worked explanation. Use natural anchors such as “free reasoning practice” or the IQTestReal brand. Never request an exact-match anchor or a reciprocal link.

## Personalization rules

1. Read the prospect’s current page and identify the exact paragraph or resource list where the guide could help.
2. Mention one specific fit; do not send a generic SEO pitch.
3. Explain that IQTestReal is a free, non-clinical practice tool and do not claim scientific validation.
4. Offer the URL as an optional reference. Do not ask for a guaranteed follow link.
5. Record the date, page, and outcome in the CSV before any follow-up; one respectful follow-up is enough.

## Prospect notes

- Edutopia explicitly says it does not accept paid content, link exchanges, or payments for follow links. Treat it as an editorial/story idea only, not a link request.
- TeachThought describes a focus on critical thinking and classroom practice, so a teacher-facing worked puzzle or reasoning reflection may be relevant if it meets their editorial bar.
- Math Is Fun welcomes useful links and has a large puzzle index; offer an original worked explanation, never copied content. Follow its usage guidance and ask before any commercial reuse.
- Education World publishes teacher resources and has a feedback/contact route; pitch a classroom-safe reasoning activity only if it is genuinely useful to their audience.
- OpenStax is a high-authority open-education publisher, but it is not a general backlink target. Use the contact/support route only for a legitimate open-learning collaboration, not a promotional link request.

The verified URLs and current status are tracked in `docs/seo/backlink-prospects.csv`. No outreach has been sent.

## Manual execution and measurement

1. Merge/deploy only after approval and check each target URL publicly.
2. Read the current submission policy and choose a relevant article/resource on the prospect's site.
3. Tailor the draft to that page without implying a relationship or prior use that did not happen.
4. Send manually only with the owner's approval; record date, target URL and outcome in the CSV.
5. Respect refusals and no-contact policies. Do not automate follow-ups or demand followed links.
6. Measure actual referral visits and relevant earned references separately from messages sent. Neither outreach nor schema guarantees rankings or AdSense approval.
